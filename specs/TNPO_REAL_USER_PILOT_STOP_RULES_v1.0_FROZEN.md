# TNPO Real-User Pilot
## STOP-THE-LINE Rules v1.0 — FROZEN

### Immediate participant/session stop
- participant asks to stop or withdraw;
- participant declines to continue;
- materially wrong authoritative instructional content could misteach;
- governance integrity breach;
- provenance/event-log failure;
- unintended participant-data exposure;
- nonrecoverable application failure.

### Not a stop condition by itself
- confusion;
- dislike;
- hesitation;
- unexpected but safe self-report;
- disagreement with system inference;
- preference for alternate wording/navigation;
- poor task completion.

### Change-control rule
No mid-cohort design change unless an STL rule requires it.

If a correction is made:
- bump build version;
- preserve prior failure;
- do not pool old/new versions as one unchanged cohort;
- preregister replacement testing before collection.
